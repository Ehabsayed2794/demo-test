Design note

Mapping

  • Flow: S36 Ranked → Confirm → this screen (S55) → Match Found, or S56. This page has no configuration; Game Type, Calculation, Bot Difficulty, Personality and Timer stay on S36.
  • Lifecycle: SEARCHING → FAILED / TIMED OUT → Try Again (back to SEARCHING) or Cancel. Cancel exists in every state, so there is no uncancelable spinner.
  • Pool (RD9): the ladder is read-only. It highlights the player's tier and the one below as the server-derived pool. No selector, no opt-up, no Skill Band.
  • Human vs human: empty seats read "Waiting for a player". No bot appears in Ranked.
  • Capabilities: one line stating no voice chat and no pause vote. No Spectate, Chat or Mic controls.
  • No invented data: no queue size, wait estimate, RP, season or timeout length. Only the elapsed timer, which the client can measure.

Tokens

All colors and fonts come from the existing page: Background, Panel, Pill, Ink, InkDim, InkFaint, Accent family, Error #F25555 (dot, border and icon on S56 only). No new tokens. The one addition is the Arabic face (Noto Naskh Arabic) for the rank title; native should use its system Arabic face.

Open items for review

  • "Gold" and "معلم" are samples bound to server rank. Arabic titles per UI_UX_ROADMAP.md RD1: مبتدئ, لاعب, معلم, وزير, أمير, سلطان, ملك.
  • Cancel on S56 returns to S36 (Ranked state), the config the player launched from, so Game Type can be adjusted and the search retried. Lobby is reserved for terminal match outcomes.
  • Match Found (MATCH_FOUND) is a separate screen and is not drawn here.
  • The elapsed timer and the three Waiting seats are the only live elements. The timer is elapsed only, never a countdown; the pool resolver publishes no ETA.
