# Estimation Ranked Home S45 - package

Open any HTML file in a modern browser (double-click, or File > Open).

- Estimation Ranked Home S45.html - main screen (the canvas, 932x430).
- Estimation Ranked Home S45 standalone.html - standalone export of the same screen, for offline or single-file use.
- S45 standalone src.html - source version of the standalone build.

Fonts load from Google Fonts, so an internet connection is needed for the intended typefaces.
No other local files are required.
