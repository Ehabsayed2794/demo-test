Bronze III at 0 RP appears only as Path B's outcome. Voice, disconnect and pause controls are absent. No season chip (S45/S54).

  • Progression wording: see assumption 2.

The equal-dignity rule the design follows is the roadmap's §4b.2 clause either way; the owner needs to reconcile the roadmap with the package.
