State notes

  • 1 Division step. Gold I → Gold II, 825 → 700. Same tier: shield initial (G), Arabic title (معلم) and identity slot are identical on both chips; only the division pill and bound change. One rung, not two.
  • 2 Tier demotion. Platinum III → Gold I, 1,000 → 825. Shield initial (P → G) and Arabic title (وزير → معلم) change. The destination is division I, set in the same pill, name size and bound as every other division, and restated in one plain line below the statement.
  • Hierarchy. Both chips are one size class (84px shield, 32px name). The current rung takes Ink and the raised SurfaceHigh card; the previous rung takes InkDim on Surface. Tags PREVIOUS / CURRENT carry the roles in text, so the thin border is never the only carrier.
  • Optional protected / no-transition frame: not drawn. It would need an assumption about RD7's consumption rule (OPEN_DECISIONS #3), which is unwritten. The shield and countdown are S51's.
  • Settling. Skeleton for both chips and the statement with “Settling your rank…”. No number is drawn.

Binding

window.rankDownBinding (rank-down-s53.js): {from, to} are ladder indices (0–18); rp is a sample (812, 988), server-owned. The script warns if a binding is not one rung down or the RP falls outside [RP[to], RP[from]). Rung bounds are real ladder values.

Motion, tokens, flags

  • Motion. Previous rung fades 0–600ms; link draws 500–1100ms; current rung fades in and settles 5px down 1000–1950ms, its border arriving with it; statement fades 1500–2200ms. No count-up, shake, flash, glow or loop. Reduced motion: no animation, the end state (5px down, border present) shows at once and the copy states the fact. Only the settling shimmer loops, as sanctioned.
  • Muted border. 1px Error #F25555 at 40% opacity on the current card only. This is the token at reduced opacity, not a new hue; flagged in case the owner reads it as a derived value. Measured: 1.83:1 against SurfaceHigh (1.84:1 on Surface, 1.82:1 on Background); full-strength Error on SurfaceHigh is 5.17:1 and no alpha below 1.00 reaches 3:1. The border is therefore decoration, not a WCAG 1.4.11 signal — the PREVIOUS / CURRENT tags and the statement carry the state, and the border must never be its sole carrier. It is never text, fill or icon.
  • Kicker colour. Set in InkDim, not InkFaint. Measured on this delivery (2026-10-17, .scr gradient composited, sampled at the text's own glyph run): the 10px kicker is 6.65–6.77:1 in InkDim and 4.59–4.65:1 in InkFaint — so InkFaint clears 4.5:1 only at the left edge of the top band; at the backdrop's brightest point (top-centre, inside the warm radial) InkFaint is 4.20:1 and fails, while InkDim stays at 6.11:1. Tokens §5 ("prefer InkDim over the background") is the rule being applied, not a local contrast rescue. Tags PREVIOUS / CURRENT likewise: 7.06:1 on Surface, 6.68:1 on SurfaceHigh.
  • Not in the token set (flagged, not invented). The shell backdrop gradient is inherited from .scr in placement-base.css. Mono labels “FINAL RP”, “PREVIOUS”, “CURRENT” have no token role of their own.
  • No Mini marker, no pacing figure, no delta, no Match-King gold.
