State notes — which ladder fact each variant expresses

  • 1 Division step. Gold III → Gold II: one rung, same tier. Same shield initial (G), same Arabic title, same slot. No tier change is implied; the foot carries only the statement.
  • 2 Tier promotion. Gold I → Platinum III: tier name, shield initial, and Arabic title (معلم → وزير) change; the destination division III sits in the same pill size as variant 1's and is restated in one line. No "TIER UP" flag, divider or recolour was added.
  • 3 Reaching King. Royal I → King: no division pill, no next rung, no continuation bar, no crown, no gold. Larger isolated shield, centred in open space; the previous rung recedes to the left. Dignity comes from scale and stillness.

Binding

window.rankUpBinding (rank-up-s52.js): {from, to} are ladder indices (0–18); rp is a sample. Server settles RP; the client never computes it.

Open decisions — designed around

  • 1 Tier tokens. Each rung's identity is one slot: shield ring --tier-ring, text --tier-ink, letter in .slot. Unset today, so neutral (Ink / InkFaint). A seven-colour decision changes that slot only. Gate #2's Royal clause cannot be met today.
  • 2 S52 / S57 boundary. No back, dismiss, or play-again chrome; each frame stands inside either flow.
  • 3 Copy. Every non-structural string is flagged draft above.
  • 4 King. No approved ceremonial token. Dignity comes from composition and restraint; a future rank emblem may want to own this moment.
  • 5 game-state.js seed. Not used.

Motion, tokens, flags

  • Motion. Previous rung fades 0–600ms; link draws 500–1100ms; new rung rises 5px and fades in 1000–1950ms; glow ramps 1300–2200ms and then holds still; text fades 1500–2200ms. No count-up, shake, flash, or loop. Reduced motion: no animation, the end state (lifted 5px, glowed, previous rung dimmed) is shown at once. Only the settling shimmer loops, as sanctioned.
  • Gold. The frame has no action, so Gold is unused; the glow is neutral Ink at low alpha. Nothing on the King rung is gold or crowned.
  • Kicker colour. Set in InkDim, not InkFaint: at 10px over the backdrop's warm radial, InkFaint falls under 4.5:1.
  • Not in the token set (flagged, not invented). The shell backdrop gradient is inherited from .scr in placement-base.css. Mono label "SETTLED RP" has no token role of its own.
  • No Mini marker, no pacing figure, no delta.
